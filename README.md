# Ubiquitous Carnival

A lightweight calculator built with plain HTML, CSS, and JavaScript. No dependencies or build tools required.

## Run it

Open `index.html` in a modern web browser.

## Features

- Addition, subtraction, multiplication, and division
- Percent and positive/negative controls
- Keyboard support: number keys, `+`, `-`, `*`, `/`, `.`, `Enter` (calculate), `Escape` (clear), and `Backspace`
- Responsive layout and accessible button labels
- Handles division by zero with an error message
